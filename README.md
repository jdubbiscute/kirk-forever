# Kirk Forever Website

Files:
- `index.html`
- `kirk-logo.png`
- `kirk-banner.png`

## Publish with GitHub Pages
1. Upload all three files to the root of your public `kirk-forever` repository.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Your site should publish at:
   `https://jdubbiscute.github.io/kirk-forever/`

Before publishing, replace the X link in `index.html` with your actual X profile URL if desired.
